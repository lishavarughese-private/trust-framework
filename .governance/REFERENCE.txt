# Governance Repository Reference
# This project inherits governance from the centralized governance repository

governance_repo: https://github.com/lishavarughese-private/trust-framework-governance
governance_version: v1.0
inheritance_model: HYBRID (local rules extend global, never weaken)

## How This Works

1. Global governance rules live in trust-framework-governance repo
2. This project (trust-framework) inherits ALL global rules
3. This project adds LOCAL rules in spec-kit/CONSTITUTION.md (extends only)
4. CI/CD fetches governance repo at build time

## Update Governance Version

When global governance updates:
1. Global repo tags new version (v1.1, v1.2, etc)
2. Update this file: governance_version: v1.1
3. Re-run CI to validate inheritance

## Cannot Weaken Global Rules

Product team CANNOT:
- Remove global security rules
- Weaken PII encryption requirements
- Remove GDPR/compliance checks
- Override global principles

Local Constitution MAY:
- Add stricter rules than global
- Add product-specific gates
- Add domain-specific requirements

See: spec-kit/CONSTITUTION.md (Extends From: governance/CONSTITUTION.md v1.0)
