# 📝 Project Brief
> Persona: Tourist
Problem: Needs a simple fast way to reserve a car
In Scope: Browse cars, select dates, confirm booking
Out of Scope: Payment, real inventory, verification
Requirements:
- Browse cars
- Select dates
- Submit booking
Acceptance Criteria:
- Valid dates → booking succeeds
- Missing fields → errors
Success Metrics:
- 100% bookings saved
- No console errors
Risks:
- Invalid dates
